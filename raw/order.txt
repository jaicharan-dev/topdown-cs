cn.txt

Here's the full bank, reordered by ideal learning sequence (bottom-up through the stack: data link → network → transport → application → practical/advanced → integrative) rather than the order we covered them in:

1. **[Easy]** What is the OSI model, and why do we use a layered architecture instead of a single monolithic system for networking? Name the 7 layers in order, and explain how the OSI model maps onto the 4-layer TCP/IP model actually used in practice.

2. **[Easy]** A sender wants to transmit the data byte `1001101` using a single even parity bit. (a) Determine the parity bit and the final transmitted sequence. (b) The receiver receives `10011010` — using even parity, determine if an error occurred. (c) Explain why a 2-bit error would go completely undetected by this scheme.

3. **[Medium]** A sender needs to transmit two 8-bit segments, `10101001` and `00111001`, using the Internet checksum method. (a) Compute the checksum sent with the data. (b) Explain how the receiver uses it to detect an error. (c) What's a key limitation of checksum compared to CRC?

4. **[Hard]** A sender wants to transmit `1101011011` using CRC with generator polynomial `x⁴ + x + 1` (bit pattern `10011`). (a) Determine the number of CRC bits needed and why. (b) Perform the binary (XOR) division to compute the CRC remainder. (c) Explain how the receiver's division confirms whether an error occurred.

5. **[Hard]** A sender wants to transmit the 4-bit data `1011` using Hamming code for single-bit error detection and correction. (a) Determine how many parity bits are needed and why. (b) Determine their positions and compute their values. (c) If a single bit is flipped in transit, explain how the receiver identifies exactly which bit is in error.

6. **[Medium]** A network transmits frames with a 1500-byte payload, a 40-byte header, and a 4-byte trailer. (a) Calculate the framing efficiency as a percentage. (b) Recalculate for a 100-byte payload and explain why smaller payloads hurt efficiency disproportionately. (c) Explain why protocols don't just maximize frame size to chase efficiency.

7. **[Easy]** What's the difference between a public and a private IP address? Why do private IPs need NAT to access the internet, and what IPv4 problem did NAT solve at scale?

8. **[Medium]** Given IP `192.168.10.75` with subnet mask `255.255.255.192`, determine: (a) the network address, (b) the broadcast address, (c) the valid host range, (d) the number of usable hosts. Show the binary breakdown of the last octet.

9. **[Medium]** A company is given `172.16.0.0/16` and needs to divide it into 6 departments, the largest needing up to 1000 hosts. (a) What subnet mask satisfies this? (b) How many subnets does this create, and how many usable hosts per subnet? (c) Is there wasted address space, and how much?

10. **[Easy]** What's the fundamental difference between TCP and UDP? Give a real-world example where UDP is deliberately chosen over TCP, and explain why reliability is sacrificed there.

11. **[Medium]** Walk through the TCP 3-way handshake — what's exchanged at each step, and why 3 steps instead of 2? Then explain why termination takes 4 steps instead of 3, and what a "half-closed" connection means.

12. **[Medium]** Define flow control and congestion control — what does each protect against, and what problem is unique to each? Name at least one congestion control algorithm (e.g. Slow Start, AIMD).

13. **[Medium]** A sender transmits a 2 MB file over a 10 Mbps link. Distance is 2000 km, signal speed 2×10⁸ m/s. (a) Calculate transmission delay. (b) Calculate propagation delay. (c) Calculate total time, and explain why these two delays are genuinely separate quantities.

14. **[Medium]** A link has bandwidth 5 Mbps and propagation delay 20 ms. (a) Calculate the bandwidth-delay product and state what it represents. (b) For Stop-and-Wait ARQ sending 1000-bit frames, calculate link utilization. (c) Explain why Stop-and-Wait becomes inefficient on long fat networks, and name the fix.

15. **[Hard]** Using the same link (5 Mbps, 20 ms delay), a sender now uses Sliding Window ARQ with 1000-bit frames. (a) Calculate transmission time per frame and the ratio `a` (propagation delay / transmission time). (b) Determine the minimum window size for full link utilization using `N = 1 + 2a`. (c) If the actual window size is half of that, what's the resulting efficiency?

16. **[Medium]** Walk through how a browser resolves a domain name to an IP — the order of caches checked, and what happens during the recursive lookup (root → TLD → authoritative). What's the difference between a recursive and an iterative DNS query?

17. **[Easy]** What are the main components of an HTTP request? What does HTTPS add on top of HTTP, and name 3 common HTTP status codes with what each signifies.

18. **[Medium]** Compare cookie-based session authentication with token-based (JWT) authentication. Where is state stored in each, and what's the key tradeoff between scalability and revocation/control?

19. **[Medium]** Explain the difference between a forward proxy, a reverse proxy, and a load balancer. How does a CDN fit in, and what's a scenario where you'd deploy all three together to scale a web application?

20. **[Medium]** Compare HTTP polling, long polling, and WebSockets for a real-time feature. What overhead does each carry, and what architectural tradeoff do you accept by adopting WebSockets at scale?

21. **[Medium]** What is CORS, and why does it exist? What's a "preflight request," when is it triggered, and how would a backend fix a CORS error for a legitimate cross-origin frontend?

22. **[Hard]** Walk through the TLS handshake — what happens between TCP connection and encrypted HTTPS readiness? Why does TLS use both asymmetric and symmetric encryption, and what role does the server's certificate play in preventing a MITM attack?

23. **[Easy]** Give a one-line comparison of HTTP/1.1, HTTP/2, and HTTP/3. What problem does HTTP/2 multiplexing solve, and why does HTTP/3 move to QUIC over UDP?

24. **[Medium]** What is idempotency in API design, and why does it matter for payment/financial endpoints? How does an idempotency key prevent a duplicate operation (e.g. a double charge) on a retried request?

25. **[Easy]** What is HTTP caching, and how do `Cache-Control` and `ETag` work together to reduce redundant data transfer? What does a `304 Not Modified` response mean and when is it used?

26. **[Hard]** Walk through everything that happens from typing a URL and hitting Enter to the page fully rendering — DNS resolution, TCP handshake, TLS handshake (if HTTPS), the HTTP request/response cycle, and caching along the way.
